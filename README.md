# GeoTime — Historical Borders

Interactive historical atlas built with D3.js. Browse country and polity borders from 3400 BCE to the present day.

## Setup

```bash
npm install
npm run dev
```

## Datasets

- **CShapes 2.0** — Global country borders, 1886–2019
- **CHGIS v6** — Chinese prefectures, 224 BCE–1911 CE
- **Cliopatria** — Global polities, 3400 BCE–2024 CE
